# SQL-портфолио: Анализ базы данных Sakila

## О проекте
Проект демонстрирует навыки SQL на реальной базе данных **Sakila** (прокат фильмов).  
Уровень запросов: от базового до продвинутого (Middle).

## Цель: показать умение решать бизнес-задачи с помощью SQL.

## Используется:
- MySQL 8.0.46
- База данных: Sakila

## 📂 Структура портфолио

sql-portfolio/
├── 01_schema/ # Схема БД (если потребуется)
├── 02_queries/
│ ├── basic/ # Базовые SELECT, WHERE, ORDER BY
│ ├── aggregations/ # GROUP BY, HAVING, агрегатные функции
│ └── advanced/ # CTE, оконные функции, EXISTS, LAG/LEAD
└── 03_documentation/ # Описание запросов

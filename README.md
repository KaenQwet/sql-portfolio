# SQL-портфолио: Анализ базы данных Sakila

## О проекте
Проект демонстрирует навыки SQL на реальной базе данных **Sakila** (прокат фильмов).  
Уровень запросов: от базового до продвинутого (Middle).

## Цель: показать умение решать бизнес-задачи с помощью SQL.

## Используется:
- MySQL 8.0.46
- База данных: Sakila

## Структура портфолио

sql-portfolio/
  01. Schema/ # Схема БД 
  02. Queries/
    02.1 Basic/ # Базовые SELECT, WHERE, ORDER BY
    02.2 Aggregations/ # GROUP BY, HAVING, агрегатные функции
    02.3 Advanced/ # CTE, оконные функции, EXISTS, LAG/LEAD
  03.documentation/ # Описание запросов
